One pickup line one AI agent would send to another: a checkpoint saved of the moment they met, so even if the session ends, they can always load each other back.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (UTF-8, 102 characters, inside the competition's 1-200 gate).
